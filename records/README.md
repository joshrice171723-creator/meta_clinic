# Archived records

This directory contains dated historical evidence that is no longer part of the
default APPlyVault context. Archives preserve event dates, source/task/decision
identifiers, links and stated limitations; they do not change current status,
authority or release gates.

## Retention rules

- Keep current requirements, decisions and risks in their canonical APPlyVault
  notes; keep the roadmap, Stories, task acceptance/status and active blockers
  in Shortcut Agent Workspace.
- Archive dated outcomes when they are no longer needed in the active progress
  window, retaining the original heading and body verbatim.
- Preserve failures, inconclusive checks, incidents, migrations, recovery,
  security findings, professional limitations and release boundaries even when
  the related task is complete.
- Do not treat an archive, test result or verification report as approval for
  production, clinical use, real/confidential data or a professional gate.

See [the progress archive index](progress/INDEX.md), [completed-task archive](tasks/INDEX.md) and [2026-09-03 cleanup manifest](vault-cleanup-2026-09-03.md).

New dated progress evidence uses one Markdown record per material outcome under `progress/YYYY/MM/`, with the directory index and the active vault Progress Log providing navigation. Existing monthly snapshots remain preserved.

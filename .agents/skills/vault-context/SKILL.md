# Vault context

Use `APPlyVault` as the software knowledge base, not as agent procedure.

1. Read `APPlyVault/00 Home.md`, `APPlyVault/01 Table of Contents.md` and `APPlyVault/AGENTS.md`.
2. Select the relevant context route from the table of contents. Read complete relevant sections, including frontmatter, scope/limits, linked decisions, risks and dated evidence.
3. Follow only dependencies needed to answer or act. Do not read the full vault by default.
4. Reconcile current source with notes when the question concerns implemented behavior. Dated evidence remains dated; absence of a note is not evidence that a fact is false.
5. Keep reported facts, direct observations, sourced background, proposals and accepted decisions distinct. Unknown facts remain unknown.
6. Return or use a compact context packet: selected sources, current direction, applicable constraints, material gaps/conflicts and the next relevant gate. Do not create a task list in the packet.

Do not place procedure, mode behavior or tool-specific instructions in the vault. Propose those changes in the agent harness instead.

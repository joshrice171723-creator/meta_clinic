# Research workflow

## When to use

Use for public sources, vendor behavior, law/regulation background, professional questions or external technical documentation.

## Procedure

1. Read the TOC route and current Source Register/relevant issue before searching.
2. Form generic public queries. Never send vault text, applicant identifiers, patient information, credentials or confidential facts to search services.
3. Prefer primary, authoritative and current sources. For technical questions, use official documentation or upstream source.
4. Record publication/update date, access date, jurisdiction/version, exact applicability and limitations.
5. Separate direct observation, sourced background, inference and proposal. State when a page could not be retrieved or a source was not reviewed.
6. Add or update the owning research note and Source Register only when new evidence belongs there; route open applicability to existing L-/R-/A-/T- items.
7. Recheck temporally unstable claims when relied upon. Do not treat a vendor badge, proposal, summary page or prior attorney involvement as case-specific approval.

## Authority limits

Research does not authorize outreach, account creation, professional engagement, purchase, filing, integration, deployment or patient-data access. Qualified reviewers make the professional or case-specific determination.
